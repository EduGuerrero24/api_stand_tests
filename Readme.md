Proyecto para la creació de usuario para la aplicación Urban Gorcers
- Esté proyecto automatiza el flujo de interacción para el campo "FirstName" de la aplicación
- "FirstName" es un campo obligatorio para la creación de un usario
- Se realizarón nueve pruebas para validar la funcionalidad del sistema


Técnologías empleadas
- Python: Lenguaje de programación principal para la automatización de pruebas
- PyCharm: Entorno de desarrollo integrado (IDE)
- Requests: Biblioteca de Python para realizar solicitudes HTTP a la API
- GitHub: Plataforma para el control de versiones y colaboración
- Git Bash: Herramienta de línea de comandos para el control de versiones
